# Перелік умовних позначень

::: {.abbreviations}
люд.-год – людино-година

ОС – операційна система

СКБД – система керування базами даних

ФВ – функціональна вимога

API – Application Programming Interface, прикладний програмний інтерфейс

CI – Continuous Integration, безперервна інтеграція

CSS – Cascading Style Sheets, каскадні таблиці стилів

DTLS – Datagram Transport Layer Security, протокол захисту транспортного рівня для датаграм

EF – Environmental Factor, коефіцієнт середовища

FK – Foreign Key, зовнішній ключ

HLS – HTTP Live Streaming, протокол потокової передачі через HTTP

HTTP – HyperText Transfer Protocol, протокол передачі гіпертексту

HTTPS – HyperText Transfer Protocol Secure, захищений протокол передачі гіпертексту

ICE – Interactive Connectivity Establishment, протокол встановлення інтерактивного з'єднання

ID – Identifier, ідентифікатор

IPC – Inter-Process Communication, міжпроцесна взаємодія

ISO/IEC – International Organization for Standardization / International Electrotechnical
Commission, Міжнародна організація зі стандартизації / Міжнародна електротехнічна комісія

JSON – JavaScript Object Notation, текстовий формат обміну даними

JWT – JSON Web Token, вебтокен у форматі JSON

OAuth – Open Authorization, відкритий протокол авторизації

OBS – Open Broadcaster Software, програма для запису та трансляцій

ORM – Object-Relational Mapping, об'єктно-реляційне відображення

PF – Productivity Factor, коефіцієнт продуктивності

PID – Process Identifier, ідентифікатор процесу

PK – Primary Key, первинний ключ

PKCE – Proof Key for Code Exchange, ключ підтвердження для обміну кодом

REST – Representational State Transfer, передача стану представлення

RFC – Request for Comments, серія документів IETF

RTMP – Real-Time Messaging Protocol, протокол обміну повідомленнями в реальному часі

RTP – Real-time Transport Protocol, транспортний протокол реального часу

SFU – Selective Forwarding Unit, вузол селективного пересилання

SRTP – Secure Real-time Transport Protocol, захищений транспортний протокол реального часу

TCF – Technical Complexity Factor, технічний коефіцієнт

TCP – Transmission Control Protocol, протокол керування передачею

UAW – Unadjusted Actor Weight, нескоригована вага дійових осіб

UCP – Use Case Points, точки варіантів використання

UDP – User Datagram Protocol, протокол користувацьких датаграм

UML – Unified Modeling Language, уніфікована мова моделювання

UUCW – Unadjusted Use Case Weight, нескоригована вага варіантів використання

UUID – Universally Unique Identifier, універсальний унікальний ідентифікатор

WebRTC – Web Real-Time Communication, технологія обміну медіаданими в реальному часі у браузері
