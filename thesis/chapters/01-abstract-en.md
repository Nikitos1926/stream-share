# ABSTRACT

Kabakov N. S. Web service for streaming media content with the function of capturing individual
applications : bachelor's qualification work in the specialty «121 Software Engineering» / Nikita
Serhiiovych Kabakov ; supervisor Andrii Valeriiovych Lapaiev. – Odesa : Odesa Polytech. Nat.
Univ., [ПОТРЕБУЄ УТОЧНЕННЯ: year]. – 107 p.

The qualification work contains the main text part on 80 pages, a list of used sources with 30
titles on 3 pages, an appendix on 17 pages.

The purpose of the qualification work is to improve the efficiency of broadcasting individual
applications by developing a media streaming web service with a desktop capture application that
delivers to viewers in the browser the picture and own sound of the selected application only and,
without any action from the streamer, switches the broadcast to a new window of that application
within 1.5 s. The object of the work is the process of broadcasting individual applications to viewers in real
time, the subject is the methods and software means of capturing the picture and sound of an
individual application, automatically switching the broadcast between its windows and delivering
the media stream to viewers over WebRTC.

The work analyses existing solutions, estimates the effort with the use case points method, designs
and implements a web application, a signaling server with an SFU media server and a desktop
application based on Next.js, mediasoup and Electron. The system delivers to viewers in the browser
the picture and own sound of the selected application only and switches the broadcast to its new
window within 1.5 s. Of 30 automated functional test cases, 27 produced the expected result; the
authorization defects are identified as a direction for further work.

Keywords: web service, media streaming, application capture, process audio capture, WebRTC, SFU,
mediasoup, Electron, Next.js.
